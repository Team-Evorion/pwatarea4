
# Práctica 4 – Programación Web Avanzada

Proyecto académico desarrollado para la asignatura de **Programación Web Avanzada** de la Universidad Bolivariana del Ecuador (UBE).

## Descripción

Esta práctica consiste en el desarrollo de un **Gestor de Tareas Interactivo**, una aplicación web que permite organizar y administrar actividades personales mediante un sistema de autenticación y control de acceso por roles.

El proyecto incorpora operaciones de gestión de tareas, almacenamiento en MySQL, estadísticas y una interfaz adaptable a diferentes dispositivos.

## Funcionalidades

- Registro e inicio de sesión de usuarios.
- Autenticación mediante sesiones PHP y contraseñas protegidas con hash.
- Gestión de tareas: creación, visualización, eliminación y cambio de estado.
- Clasificación de tareas en pendientes y completadas.
- Estadísticas de tareas registradas.
- Control de acceso mediante roles de administrador y usuario.
- Panel administrativo con usuarios y tareas organizadas en listas desplegables.
- Diseño responsive para computadoras, tablets y dispositivos móviles.

## Tecnologías utilizadas

- **Frontend:** HTML5, CSS3 y JavaScript.
- **Backend:** PHP y PDO.
- **Base de datos:** MySQL / MariaDB.
- **Herramientas:** XAMPP, Git y GitHub.
- **Hosting:** InfinityFree.

## Acceso al proyecto

- **Sitio web:** https://zahiddev.infinityfreeapp.com/pwatarea4/

### Consideraciones importantes

1. El formulario de registro permite crear únicamente cuentas con el rol **Usuario**. No es posible registrar administradores desde la aplicación.
2. La versión publicada en InfinityFree dispone de **una sola cuenta administradora**, configurada previamente en la base de datos.

**Nota:** Las credenciales de acceso para las pruebas se proporcionan por separado en el documento de entrega académica.
